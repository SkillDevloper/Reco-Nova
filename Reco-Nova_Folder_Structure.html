🚀 Quick Start — Step by Step
1
Clone / Extract the project
cd reco-nova
Make sure you are inside the reco-nova/ root folder
2
Run installer
bash install.sh
Installs pip dependencies and creates the reco-nova alias
3
Load the alias (one time)
source ~/.bashrc
Or source ~/.zshrc if using Zsh
4
Verify environment
reco-nova setup
Checks Python version, pip libs, and external tools (subfinder, httpx, etc.)
5
Run your first scan
reco-nova -d example.com
Or: python3 reco_nova.py -d example.com
6
Full scan with graph
reco-nova -d example.com --full --graph
Enables all modules including attack surface graph generation
7
Modern vs Classic report
reco-nova -d example.com # Modern Bootstrap (default)
reco-nova -d example.com --simple # Classic simple HTML
Use --simple for lightweight classic report, default is modern dark theme
8
Debug mode for troubleshooting
reco-nova -d example.com --debug
Shows detailed logs and debug information during scan
9
View results
open reports/example.com_modern.html # Modern report
open reports/example.com_report.html # Classic report
Or open graphs/example.com_graph.html for interactive D3.js visualization
